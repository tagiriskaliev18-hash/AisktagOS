# AIsktagOS

**AIsktagOS** — операционная система для разработчиков на Linux со **встроенным ИИ**. Рабочий стол — «между Windows и Linux»: привычная панель задач с меню «Пуск» и значками на столе, а под ней вся свобода Linux: виртуальные столы, плитки окон, терминал, Wayland. Работает на любом x86-64 компьютере с любой видеокартой: AMD, Intel или NVIDIA.

| | |
|---|---|
| Основа | Ubuntu 24.04 LTS «Noble», поддержка до 2029 года, без snap |
| Рабочий стол | KDE Plasma 5.27 (Wayland, с запасом на X11) в раскладке «Hybrid»: панель задач снизу |
| Встроенный ИИ | **Mind**: локальная нейросеть (llama.cpp), работает без интернета, просыпается по запросу |
| Установщик | Calamares: пошаговый мастер, как у Windows |
| Файловая система | Btrfs со снимками Timeshift; снимок перед каждым обновлением, откат одной кнопкой |
| Приложения | deb-пакеты Ubuntu и Flathub через «Центр приложений» (Discover) |

## Встроенный ИИ Mind

В образ вшита модель **Qwen2.5-Coder 1.5B** (Apache-2.0): она отвечает на вопросы о коде и системе на ПК от 4 ГБ памяти, даже без видеокарты. Больше памяти — можно скачать модель посильнее (Qwen3 4B, Qwen2.5-Coder 7B) в Центре AIsktagOS.

- **Локально и приватно.** Код и вопросы никуда не отправляются, аккаунты не нужны. Сервер слушает только `127.0.0.1`.
- **Не ест память впустую.** Модель загружается по первому запросу и через 15 минут простоя выгружается (systemd socket activation).
- **Любая видеокарта.** На настоящей карте AMD/Intel/NVIDIA считает Vulkan, иначе процессор. Выбор автоматический.
- **В терминале:** `ai как распаковать tar.gz` · `git diff | ai review` · `ai why` (разбор ошибки последней команды) · `ai commit` (сообщение коммита) · **Ctrl+G** превращает описание в команду, **Ctrl+Shift+E** объясняет вывод.
- **Окно ассистента** — **Meta+A**: диалог, вложение файлов и буфера обмена, роли (программист, ревьюер, администратор).
- **Для редакторов и сторонних инструментов:** OpenAI-совместимый API `http://127.0.0.1:6573/v1`. Для VS Code подготовлен конфиг расширения Continue; `ai run aider` запускает инструмент с подключением к Mind.
- **Свой сервер по желанию:** Ollama, LM Studio или облачный OpenAI-совместимый сервис настраиваются в Центре.

Подробности — в [docs/AI.md](docs/AI.md).

## Рабочий стол «Hybrid»

**От Windows:** панель задач с меню «Пуск», закреплёнными приложениями, треем и часами в две строки; значки «Этот компьютер», «Домашняя папка», «Корзина» на столе; кнопки окна справа (свернуть, развернуть, закрыть); **Meta+E** — файлы, **Meta+R** — «Выполнить», **Meta+L** — блокировка, **Meta+Tab** — обзор окон, **Meta+1…9** — закреплённые приложения.

**От Linux:** четыре виртуальных стола в панели (**Ctrl+Alt+←/→**), плитки окон (**Meta+T**, **Meta+←/→**), терминал по **Meta+Enter** и **Ctrl+Alt+T**, Wayland, никаких принудительных аккаунтов и телеметрии.

Дизайн — единая система «Aurora»: [docs/DESIGN.md](docs/DESIGN.md). Синий — система, бирюзовый — фокус, фиолетовый — ИИ. Стекло и размытие включаются автоматически, а в виртуальных машинах без 3D интерфейс остаётся читаемым и без них.

## Любая видеокарта: три уровня запаса

1. **Обычный режим.** Wayland и аппаратное ускорение через драйвер ядра: `amdgpu`, `i915`/`xe`, `nouveau`, `vmwgfx` (VMware), `virtio-gpu`.
2. **У видеокарты нет 3D-драйвера.** Интерфейс Plasma автоматически переключается на программную отрисовку, и всё остаётся видно.
3. **Нет даже DRM-устройства** (режим `nomodeset`, очень старые видеокарты). Экран входа и рабочий стол автоматически запускаются в X11 с универсальными драйверами `vesa` и `fbdev`.

Для NVIDIA после установки откройте Центр AIsktagOS → «Драйверы» и нажмите «Установить рекомендуемые».

## Как скачать

Готовый образ публикуется на странице **[Releases](https://github.com/tagiriskaliev18-hash/AisktagOS/releases)**. Файл называется `aisktagos-1.1-amd64.iso`. Из-за встроенной модели образ около 3,5–4 ГБ и разбит на части `.part0`, `.part1`, …: скачайте все части и запустите `join-windows.bat` (Windows) или `join-linux.sh` (Linux), он склеит их в один ISO и проверит контрольную сумму.

## Установка в виртуальную машину (VMware, VirtualBox, QEMU/KVM, Hyper-V)

Ресурсы: **4 ГБ ОЗУ и больше** (лучше 8: тогда доступна модель посильнее), **2–4 ядра**, **диск 40 ГБ и больше**, UEFI или BIOS (работают оба режима).

- **VMware Workstation/Player:** тип «Linux → Ubuntu 64-bit», в «Дисплей» включите «Ускорение 3D-графики». VMware Tools уже встроены: буфер обмена, перетаскивание файлов и изменение разрешения работают сами.
- **VirtualBox:** тип «Linux / Ubuntu (64-bit)», видеопамять 128 МБ, включите EFI по желанию. Гостевые дополнения предустановлены.

Запустите ВМ и выберите «Установить AIsktagOS». **Важно:** в live-режиме всё пропадает после выключения. Если вы закрыли установщик, в Центре AIsktagOS всегда есть жёлтая плашка с кнопкой «Установить».

## Установка на другой компьютер с флешки

Так ставят систему на обычный ПК, а не в виртуальную машину. Подходят и UEFI, и старый BIOS. Secure Boot выключать не нужно: загрузчик подписан, как в Ubuntu.

> **Диск будет стёрт**, если на шаге «Разделы» оставить **«Стереть диск»**: пропадут все разделы и файлы на выбранном диске. Чтобы этого не случилось, выберите **ручную разметку** и не форматируйте разделы, которые нужно сохранить. Пункт «Установить рядом» (когда он есть) не стирает диск целиком, но сжимает уже существующий раздел.

1. Возьмите флешку на 8 ГБ или больше. Запись образа удалит с неё все данные.
2. Запишите ISO:
   - **[Rufus](https://rufus.ie)** (Windows). Выберите ISO и нажмите «Старт». Если спросит режим, выберите **«DD-образ»**.
   - **[balenaEtcher](https://etcher.balena.io)** (Windows, macOS, Linux). ISO, затем флешка, затем Flash.
   - **[Ventoy](https://www.ventoy.net)**. Один раз поставьте Ventoy на флешку и дальше просто копируйте на неё ISO.
3. Вставьте флешку в нужный компьютер, включите его и откройте меню загрузки: обычно **F12**, **F10**, **F11** или **Esc**, у HP — **F9**. Выберите флешку (в UEFI — строку с пометкой UEFI).
4. В меню AIsktagOS выберите **«Установить AIsktagOS»**. Откроется рабочий стол и установщик.
5. Пройдите мастер. Имя и пароль задаются на шаге «Пользователь»: готовой учётной записи с известным паролем нет. Диск выбирается из списка, а не по фиксированному имени вроде `/dev/sda`.
6. После копирования перезагрузитесь и выньте флешку. При первом входе откроется Центр AIsktagOS.

Гостевые дополнения VirtualBox, VMware и QEMU в образ входят, но на обычном ПК не подменяют видеодрайвер: им нужен свой гипервизор.

## Первые шаги после установки

- Откроется **Центр AIsktagOS**. Если в компьютере NVIDIA, он сразу предложит фирменный драйвер.
- Страница **ИИ Mind** покажет, какая модель подходит вашей памяти.
- Обновления: «Центр приложений» → «Обновления» или команда `update` в терминале.
- Если после обновления что-то сломалось, откройте **Timeshift** и восстановите снимок «Перед обновлением пакетов».

## Сборка образа самостоятельно

Нужен Ubuntu или Debian с правами root и около 40 ГБ свободного места:

```bash
sudo apt install debootstrap squashfs-tools xorriso grub-pc-bin grub-efi-amd64-bin mtools dosfstools
sudo ./build.sh                          # полная сборка → out/aisktagos-1.1-amd64.iso
sudo AI_BUNDLE_MODEL=none ./build.sh     # без встроенной модели: образ на ~1 ГБ меньше, сборка быстрее
sudo ./build.sh iso                      # пересобрать только ISO из готовой системы
sudo ./build.sh clean                    # удалить рабочие файлы
```

Сборка на GitHub запускается автоматически при каждом изменении (workflow `.github/workflows/build-iso.yml`): сначала быстрая проверка скриптов, параллельно полная сборка (около 1,5–2 часов). Результат появляется в Releases; сборки из веток разработки помечаются как предварительные. Запустить вручную: вкладка **Actions** → «Сборка AIsktagOS ISO» → **Run workflow**.

### Устройство репозитория

```
aisktagos/
├── config.env                  имя, версия, база Ubuntu, версии llama.cpp и lazygit, какая модель вшивается
├── build.sh                    сборка: debootstrap → пакеты → squashfs → ISO (BIOS+UEFI+Secure Boot)
├── packages/*.list             списки пакетов по группам (основа, рабочий стол, разработка, ИИ, железо, live)
├── scripts/chroot-setup.sh     настройка системы внутри образа (репозитории, пакеты, ИИ-движок и модель, службы)
├── iso/                        меню загрузки GRUB и его тема
├── overlay/                    файлы, которые кладутся в систему поверх Ubuntu
│   ├── etc/calamares/          установщик: шаги, разметка Btrfs, оформление
│   ├── etc/xdg/                настройки KDE по умолчанию (KWin, горячие клавиши, цвета)
│   ├── etc/skel/               настройки нового пользователя (zsh, kitty, VS Code, git, значки на столе)
│   ├── etc/sysctl.d, limits.d  настройки системы под разработку
│   └── usr/…                   Центр AIsktagOS, Mind, команда ai, тема окон, раскладка рабочего стола
├── assets/                     генераторы графики и дизайн-токены (tokens.py, make-*.py)
├── tools/                      test-vm.py (стенд QEMU), mock-llm.py и shot-ui.py (проверка интерфейса без ВМ)
├── docs/                       AI.md, DESIGN.md
└── AGENTS.md                   передача проекта ИИ-агенту (Claude Code, Antigravity)
```

Название, версия и язык системы меняются в `config.env`. Графику можно перегенерировать: `python3 assets/tokens.py`, `python3 assets/make-assets.py`, `python3 assets/make-aurorae.py`, `python3 assets/make-plasma-theme.py`.
