# Дизайн-система «Aurora»

Единый визуальный язык AIsktagOS: меню загрузки, установщик, рабочий стол, окна, Центр, Mind, терминал. Источник правды — [`assets/tokens.py`](../assets/tokens.py): оттуда генерируется `overlay/usr/share/aisktagos/design/tokens.json`, который читают PyQt-приложения (`aisktag_theme.py`) и генераторы графики (`make-aurorae.py`, `make-plasma-theme.py`).

## Смысл цвета

| Цвет | Значит | Где |
|---|---|---|
| Синий `accent` | система, выбранное | акцент KDE, активное окно, кнопки «Далее/Установить», боковая панель установщика |
| Бирюзовый `focus` | внимание, фокус | кромка стекла, фокус и наведение, индикаторы |
| Фиолетовый `ai` | всё, что делает нейросеть | кнопка и пузыри Mind, статус модели, значок Mind |

Логотип — градиент «фиолетовый → бирюзовый»: нейросеть, превращающаяся в систему.

## Слои

| Слой | Файл | Что сделано |
|---|---|---|
| Рабочий стол | `…/org.aisktagos.desktop/contents/layouts/…-layout.js` | панель задач снизу: «Пуск», закреплённые, 4 стола, трей, часы, «показать рабочий стол» |
| Панель | `overlay/usr/share/plasma/desktoptheme/AIsktagOS` (`assets/make-plasma-theme.py`) | стекло: размытие, а без него почти непрозрачная заливка, верхняя кромка |
| Окна | `overlay/usr/share/aurorae/themes/AIsktagOS` (`assets/make-aurorae.py`) | стеклянный заголовок, название слева, кнопки Windows справа, свечение активного окна |
| Установщик | `overlay/etc/calamares/branding/aisktagos/` | палитра приведена к токенам, слайд про ИИ |
| Центр и Mind | `aisktag-center.py`, `aisktag-mind.py`, `aisktag_theme.py` | общая тема из токенов |
| Терминал | `overlay/etc/skel/.config/kitty/kitty.conf`, `starship.toml` | цвета из токенов |

## Запасной вариант без размытия

Размытие KWin требует 3D. Без него (виртуальные машины, слабые видеокарты) панель использует вариант `widgets/panel-background.svg` с непрозрачностью 0,92, а при выключенном композитинге — `opaque/` (1,0). Заголовки окон остаются читаемыми: заливка 0,75–0,8 поверх тёмных обоев.
